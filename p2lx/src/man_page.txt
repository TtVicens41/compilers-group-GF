NAME
    lexer - lexical scanner for Practice 2

SYNOPSIS
    lexer <input_file.c>
    lexer -help

DESCRIPTION
    Reads a C source file and generates:
      1) an in-memory token list
      2) an output token file named <input_file.c>scn

    Token output format is configurable at compile time:
      - OUTFORMAT_RELEASE
      - OUTFORMAT_DEBUG

    Message destination is configurable at compile time:
      - DEBUG_ON  -> output file
      - DEBUG_OFF -> stdout

TOKEN CATEGORIES
    CAT_KEYWORD       if else while return int char void
    CAT_OPERATOR      = > + *
    CAT_SPECIALCHAR   ( ) ; { } [ ] ,
    CAT_NUMBER        [0-9]+
    CAT_IDENTIFIER    [A-Za-z][A-Za-z0-9]*
    CAT_LITERAL       "..."
    CAT_NONRECOGNIZED unsupported lexemes

COUNTERS
    Counters are enabled only when:
      COUNTCONFIG == COUNT_ENABLED and OUTFORMAT == OUTFORMAT_DEBUG

    Counters:
      COUNTCOMP, COUNTIO, COUNTGEN

    Destination:
      COUNTOUT == OUT      -> output token file
      COUNTOUT == DBGCOUNT -> <input_file.c>dbgcnt

FILES
    resources/automata.txt
        Automata specification loaded at runtime.

    src/lexer_config.h
        Compile-time configuration defaults.

EXAMPLES
    ./lexer tests/acceptance_input.c
    EXTRA_CFLAGS='-DOUTFORMAT=OUTFORMAT_RELEASE -DDEBUG=DEBUG_OFF' ./build_local.sh
